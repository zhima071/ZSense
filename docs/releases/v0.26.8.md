# ZSense 0.26.8

## 更新内容

- 桌面版新增全局截图：在“设置 → 显示”录制快捷键，默认 macOS 为 ⌘⇧8、Windows 为 Ctrl+Shift+8。可框选鼠标所在屏幕，使用画笔、画圈、矩形、箭头和文字批注，支持撤销/重做、下载 PNG、置顶贴图，以及点击 ✓ 复制到系统剪贴板并退出。
- 手机远程连接将云端和局域网入口分开；支持用设备号及 6 位配对码连接其他账号的设备，并记住已成功配对的云端设备。局域网连接失败时明确提示，不再暗中切换到云端。
- 改进手机远程打开速度：缩短附近设备扫描等待；已配对设备优先使用签名快速入场，旧版桌面仍可回退到原挑战流程。远程网页减少首次静态请求，较大的已鉴权工作区响应按需压缩，并延后加载完整会话历史。
- 手机远程会话的“选择工作区”改为在手机页面内浏览并选择桌面端工作区目录，不再弹出电脑上的文件选择窗口。
- 修复远程打开时会话内容与加载状态的若干显示问题；补充设备连接、远程工作区选择和全局截图校验。

Android 伴侣端版本为 0.1.3。使用全局截图前，macOS 可能要求在系统设置中允许 ZSense 录制屏幕。
