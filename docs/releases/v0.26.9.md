# ZSense 0.26.9

## 更新内容

- 桌面版的官方更新支持在应用内下载、校验和启动安装，不再必须跳转浏览器下载安装包。macOS 更新后自动重开应用；Windows 启动安装向导。
- 下载时显示实时速度与进度；支持暂停后断点续传。点击取消会清理未完成的下载缓存。
- 安装前核对 GitHub 官方发布的安装包地址、文件大小和 SHA-256 校验值。自定义更新源如无法满足官方校验条件，仍只提供手动下载。
- Android 伴侣端升级到 0.1.4：首页新增应用内检查更新、下载速度与进度、暂停后续传、取消清理缓存、校验后调用系统安装器。首次应用内安装时需按 Android 提示允许 ZSense 安装应用。

三个平台的安装包仍由 GitHub Releases 提供；本次没有切换到阿里云或中国内地 CDN。
