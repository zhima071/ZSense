# 安装即用的本地长期记忆

当前实现借鉴 Hindsight 的“保留（retain）—召回（recall）—修订/遗忘”工作流，但不运行或下载 Hindsight、Python、uv、嵌入模型或独立数据库。ZSense 内置 SQLite 已包含全部需要的存储与索引逻辑，首次安装即可离线使用。

- 每个 Bot（含 AI 对话空间）使用独立命名空间。聊天、消息网关、定时任务和远程任务只召回本空间记忆。
- 回复完成后仅检查用户原话；只有明确表达的长期事实/偏好才自动写入，凭据和可疑指令先过滤。相同或近似内容不会反复堆积。手动编辑、删除与修订直接作用于本机库。
- 召回使用中日韩分词片段、关键词覆盖度、记忆类型、置信度、时间及召回次数排序，并有条数和字符预算；不会把完整历史塞入每次请求。
- 已投影到 SQLite 的旧 Hindsight 事实与原有人工记忆继续保留，可查看和编辑。旧 Hindsight 独立数据库中**尚未投影**的事实不会自动读取，升级前应先确认记忆管理界面所见内容。

能力边界：这不是完整版 Hindsight 的本地 LLM 事实抽取或向量语义检索。无额外模型时，应用只对明确表达的长期信息做保守提取；隐含事实、同义表达和复杂矛盾的处理能力较弱。好处是无需首次下载、额外后台进程或模型内存，也不会把记忆内容上传到记忆服务。

验证：`npm run test:local-memory`、`npm run typecheck`、`node scripts/verify-packaged-app.mjs`。完整 Mac/Windows 安装及跨设备记忆迁移仍应分别做实机验收；“导出配置”不含会话与记忆，不能当作备份。
